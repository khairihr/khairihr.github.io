How I work

The CRM is a Laravel monolith with a Node.js service for high-volume sending, talking to Meta's Graph API and serving 200+ organizations from one codebase. The core architecture predates me. I started on bug fixes in early 2025 and grew into leading the engineering, which mostly means keeping it reliable, cleaning up what had grown messy, and building the newer systems on top.

I lean pragmatic. I'd rather ship something correct and observable than something clever, and I measure before I change anything: most of the numbers on this page started as an EXPLAIN plan, a Datadog trace or a count run against production. I also care how software feels, which is why I led the UI refresh across the product.
